# Country Development Clustering

An unsupervised machine learning project that uses KMeans clustering to group countries based on socioeconomic and health indicators.

## Project Objective

The goal is to identify groups of countries with similar development characteristics and explore which countries may require further socioeconomic assessment.

## Technologies Used
- Python
- Pandas & NumPy
- Matplotlib & Seaborn
- Scikit-learn
- Plotly

## Machine Learning
- Data preprocessing
- Feature scaling using StandardScaler
- KMeans clustering
- Hyperparameter tuning using GridSearchCV
- Silhouette Score and Inertia for evaluation
- Interactive world map visualization

## Results

Countries are grouped into three clusters based on their socioeconomic indicators. The results can help explore similarities and differences between countries.

*Note: Cluster membership indicates similarity in the selected features, not a definitive measure of aid requirements.*
